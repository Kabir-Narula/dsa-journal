# 17 — Bit Manipulation (Week 11: Feb 8 – Feb 14)

**Focus:** Core bitwise identities: XOR cancellation (`a ^ a == 0`, `a ^ 0 == a`), clearing lowest set bit (`n & (n - 1)`), and bit shifts (`<<`, `>>`). Remember Python ints have arbitrary precision — mask with `0xFFFFFFFF` for 32-bit problems.

## Triggers
- *"Every element appears twice except one"* -> XOR
- Count set bits / power of two -> `n & (n - 1)`
