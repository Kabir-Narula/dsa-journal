**Focus:** Big-O time & space analysis, dynamic arrays (`list`), hash tables (`dict`, `set`).

## Triggers
- *"Seen before / duplicate / count"* -> `set` or `dict`
- *"Pair that sums to target"* -> store the complement
- *"Group by canonical form"* -> `dict` keyed by sorted string or 26-char count tuple
- *"Top k by frequency"* -> bucket sort or heap
