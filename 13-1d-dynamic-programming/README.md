# 13 — 1-D Dynamic Programming (Weeks 9 – 10: Jan 25 – Feb 7)

**Focus:** Follow the 4-step DP method every time:
1. State in plain English: *"dp(i) is the best answer using..."*
2. Recurrence relation
3. Base cases
4. Write plain recursion -> add `@cache` (top-down) -> convert to bottom-up table if needed

## Triggers
- Overlapping subproblems + *"count the ways"*, *"min/max score reaching step `i`"*, or *"is it possible?"* -> DP
